Company Growth Signal Detector

Reads hiring patterns as alternative intelligence data

This tool treats LinkedIn job postings as alternative financial data. Scrape live hiring activity for any company using Bright Data, then pass it to Gemini to detect growth signals — department expansions, seniority shifts, tech stack pivots — before they show up in press releases.

To track different companies, edit watchlist.json and add entries with a company name and location. Then restart the server and refresh.
